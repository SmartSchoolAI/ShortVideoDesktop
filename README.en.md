## 📖 Product Overview

**ShortVideo** is an automated video generation, multilingual subtitle localization, and matrix publishing desktop/web platform tailored for global creators, educators, cross-border e-commerce sellers, and media teams.

The desktop client blends web-based studio creativity with native desktop automation, allowing creators to ideate, render, translate, format, and safely publish videos to major platforms within a single workflow.

---

## ✨ Key Features & Highlights

### 1. 🌐 14 Core High-CPM Languages Worldwide
* Handpicked coverage of top global commercial languages: **Chinese (zh)**, **English (en)**, **Japanese (ja)**, **Korean (ko)**, **Vietnamese (vi)**, **Thai (th)**, **Indonesian (id)**, **Spanish (es)**, **French (fr)**, **Portuguese (pt)**, **German (de)**, **Italian (it)**, **Russian (ru)**, and **Turkish (tr)**.
* AI-driven subtitle translation, multi-language typography, and frame-accurate audio-visual synchronization.

### 2. 🤖 Anti-Detection Social Automation (Playwright / CDP)
* Native integration for **WeChat Channels** and **Xiaohongshu (RED)** creator services.
* Powered by Chrome DevTools Protocol and Playwright, mimicking human typing rhythm, variable delays, and physical mouse movements to ensure account security.

### 3. 📚 All-Discipline Educational Content Support
* Efficient rendering for multidisciplinary topics including **English**, **Mathematics**, **Physics**, **Chemistry**, **History**, and **Geography**.

### 4. 💻 Dual Experience: Web Studio + Native Desktop App
* Rapid online browser creation in Web Studio, combined with the desktop client for seamless multi-account matrix publishing.

### 5. 💰 Pay-As-You-Go, Zero Subscription Traps
* Transparent credit-based billing without recurring memberships. Generating a single video costs approximately **¥2 - ¥4 (~$0.28 - $0.56)**.

### 6. 📱 Continuous Multi-Platform Matrix Expansion
* Fully supports **YouTube**, **WeChat Channels**, and **Xiaohongshu (RED)**; **TikTok**, **Bilibili**, **Meta (Facebook)**, and **Instagram** are continuously rolling out.

### 7. 🎙️ Premium Neural AI Voice Models
* Studio-grade voice actors with nuanced emotional rendering and flexible adaptations across dialects, personas, and tones.
