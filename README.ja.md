## 📖 ソフトウェア概要

**ShortVideo** は、世界中のショート動画クリエイター、教育・教養コンテンツ提供者、越境EC、メディア運用チーム向けに設計された動画自動生成・多言語ローカライズ・SNS自動投稿プラットフォームです。

デスクトップ版クライアントは、Webスタジオの手軽さとデスクトップならではの自動化能力を融合し、企画・動画生成・多言語翻訳から各種SNSへの安全な自動投稿までをワンストップで実現します。

---

## ✨ 主な機能と特徴

### 1. 🌐 世界14言語対応（高CPM市場特化）
* 収益性の高い14言語を網羅：**日本語(ja)**、**英語(en)**、**中国語(zh)**、**韓国語(ko)**、**ベトナム語(vi)**、**タイ語(th)**、**インドネシア語(id)**、**スペイン語(es)**、**フランス語(fr)**、**ポルトガル語(pt)**、**ドイツ語(de)**、**イタリア語(it)**、**ロシア語(ru)**、**トルコ語(tr)**。
* AIによる高精度な字幕翻訳、多言語レイアウト調整、フレーム単位の音画同期。

### 2. 🤖 安全なSNS自動投稿機能（Playwright / CDP）
* **微信視頻号（WeChat Channels）** や **小紅書（RED）** クリエイタープラットフォームに対応。
* 人間らしいタイピング速度やランダムな待機時間、マウス操作を再現し、ボット検知やアカウント凍結のリスクを徹底排除。

### 3. 📚 幅広い教育・教養ショート動画の制作
* **英語**、**数学**、**物理**、**化学**、**歴史**、**地理** など全教科の解説動画を高速レンダリング。

### 4. 💻 Webスタジオ ＋ デスクトップアプリの両立
* Webブラウザ上でのスピーディーな制作と、デスクトップアプリによる複数アカウントのマトリクス自動投稿がシームレスに連携。

### 5. 💰 明朗な従量課金制（月額縛りなし）
* サブスクリプション契約の強制なし。使った分だけポイントを消費する透明な料金システム。動画1本あたりわずか **約40〜80円（2〜4元）**。

### 6. 📱 マルチプラットフォーム展開
* **YouTube**、**微信視頻号**、**小紅書** に正式対応。**TikTok**、**Bilibili**、**Meta（Facebook）**、**Instagram** も順次対応予定。

### 7. 🎙️ リアルなニューラルAI音声モデル
* 各言語やキャラクター、感情のトーンに合わせた自然で豊かなナレーション音声を搭載。
