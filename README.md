## 📖 软件定位与概述

**ShortVideo** 是一款面向全球短视频创作者、知识科普博主、跨境电商与矩阵运营团队的自动化短视频生成、多语言字幕本地化与矩阵安全发布平台。

桌面客户端深度融合了 Web 端的快速创作能力与桌面级自动化操作，让创作者能够在一个客户端内完成视频构思、脚本生成、多语言本地化排版，并一键安全发布到各大主流社交平台。

---

## ✨ 核心功能与特色亮点

### 1. 🌐 全球 14 种核心高 CPM 语言覆盖
* 精选覆盖全球商业变现价值极高的 14 种语言：**中文(zh)**、**英语(en)**、**日语(ja)**、**韩语(ko)**、**越南语(vi)**、**泰语(th)**、**印尼语(id)**、**西班牙语(es)**、**法语(fr)**、**葡萄牙语(pt)**、**德语(de)**、**意大利语(it)**、**俄语(ru)**、**土耳其语(tr)**。
* 具备智能字幕翻译、高质量本地化排版与毫秒级动态音画同步。

### 2. 🤖 拟真自动化社交平台安全发布 (Playwright / CDP)
* 原生集成 **微信视频号 (Channels)** 与 **小红书 (RED)** 创作者服务平台的自动化发布引擎。
* 基于 Chrome DevTools 协议与 Playwright，完全模拟真人打字节奏、随机间隔与物理操作交互，彻底规避机器人行为识别与封号风险。

### 3. 📚 全学科短视频创作支持
* 深度支持知识科普与教学短视频的高效渲染与生成，覆盖 **英语**、**数学**、**物理**、**化学**、**历史**、**地理** 等全学科内容。

### 4. 💻 Web 端在线制作 + 桌面客户端双重体验
* 支持在浏览器（Web 端）在线快速构思与制作短视频；
* 配合桌面客户端，无缝执行多账号矩阵自动化上传与一键发布。

### 5. 💰 按需扣费，透明无会员绑架
* 采用充值积分、按需实用实扣的计费机制，无任何强制按月/按年订阅绑架。
* 单条高质量短视频生成成本仅需 **2 - 4 元** 左右，性价比极高。

### 6. 📱 持续进化的多平台发布生态
* 已全面支持 **YouTube (油管)**、**微信视频号**、**小红书** 等主流流量阵地；
* **抖音**、**B站**、**META (Facebook)**、**Instagram** 等平台正持续快速接入中。

### 7. 🎙️ 丰富顶尖神经网络声音模型
* 内置丰富的多语种高保真 AI 音色库，支持根据语种、剧情角色与情绪氛围灵活切换，带来逼真自然的听觉体验。
